# D03 — Database tree and global source manager

Implemented in `mods/codenav/database.js`; the public plain implementation classes are `Database` and `DatabaseManager`, plus `openDatabaseManager(options)` for callers. Parent integration registers `database` and `database-manager`. The Database body adds no second tool title or action bar.

The manager uses the common settings shell at a definite 900×680 size, native retained inputs, a masked password input, and a virtual source list controlled by `MenuController`. It supports new/edit/save/delete and optional draft connection tests for MySQL, MariaDB, PostgreSQL, SQL Server, and SQLite. Network forms expose host, port, user, password, database and TLS (`""`, `disable`, `require`, `verify-full`); new network profiles default to verified TLS, while existing profiles retain their setting. SQLite uses a file path. Saving does not require a successful test. Delete is confirmed by a second inline Delete action.

Sources are fetched from the engine's global `db_sources` endpoint, without deriving IDs from the current space. Public metadata is whitelisted before retaining engine responses. Password text is never stored in shared state or overlay props; unchanged passwords are omitted from requests so the engine retains its session password. Native password state is cleared and released on close. The form explains that passwords are available only for the engine session. Successful metadata changes publish only an opaque revision; live Database bodies reload sources after that revision changes.

The tree lazily loads database/schema/table/view/column catalog children. It preserves object context when constructing descendant requests, shows actual loading/errors with retry and empty states, and discards responses after refresh or close. A virtual list with native scrolling and `MenuController` owns focus and navigation. Pointer modifiers support Ctrl/Command toggles and Shift ranges. Home/End/PageUp/PageDown/Up/Down, expand/collapse, parent/child movement, Enter and select-all operate on the visible tree. Table/view double-click opens data.

Context menus use the common `uiMenu` renderer and an opening-time metadata snapshot, with Open Data, New Query Console, Generate DDL and source management. Mixed selections are grouped by source and dispatched through the exact `codenav.database-open:` JSON command contract. A selected column requests its owning table definition. Database/schema/table mixed selections remain intact for the engine's ancestor deduplication. No selected source identity depends on the active workspace.
