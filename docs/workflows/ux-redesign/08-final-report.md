# 현재 보고 — ADE 재구성 제안

2026-11-06. 실행 모드: 계획 수립. 이번 범위의 제안 문서 작성 완료, 전체 제품 목표는 미완료다.

[재구성 제안](12-ade-rebuild-plan.md)은 사용자의 ‘한 ADE에서 대부분의 개발 작업’ 목적, 승인 데모 기반 새 화면/상태 흐름, 작은 단위의 실제 검증을 반영한다. 사용자 순서를 확정안으로 취급하지 않고 구현자 권고와 근거를 함께 기록했다.

권고 순서는 UI 기반·ADE 프레임 → 핵심 ADE 작업 흐름 → 통합 편집기 → DB다. 편집기 입력·단축키·IME는 작은 선행 시험으로 위험을 확인한다. 첫 구현 단위는[T39 ADE 프레임](tasks/T39-ade-shell-rebuild.md)으로 제안한다. DB 탐색기 구현을 첫 단계로 잡았던 방향은 대체됐다.

새 구현·설치·실행 검증·커밋/푸시는 수행하지 않았다. 기존 native Cmd+A/Save/SQL shortcut 결함, HMR 불안정과 과거 부분 구현 결과는 이 계획 작성으로 해결됐다고 표시하지 않는다. 진행 상태는[00-progress.md](00-progress.md), 실제 검증 계획은[06-validation-plan.md](06-validation-plan.md)를 따른다.
