# T30 프로젝트 선택기와 공통 외곽

09/T18 기준으로 실제 프로젝트 선택기의 이중 외곽·밀도·헤더/작은 정렬 선택을 데모와 맞춘다. design/idea/ui.js, tools.js의 Projects 및 필요한 공통 gallery 예제·관련 검사만 소유한다. common.js/main.js/editor/DB/실행/설정 파일은 부모와 다른 태스크 소유다.

공통 컴포넌트가 외곽을 한 번만 소유하도록 하고 단독 메뉴/내장 목록 동작을 재사용한다. 프로젝트 이름·경로·remote·동명 구분·폴더 열기·이름/최근/직접 정렬·직접 지정 관리 목록을 보존한다. 키보드 이동·scroll·선택·Esc·현재 항목·긴 경로와 normal/compact를 검사한다. canonical 생성은 가능하지만 설치/CUA는 부모만 한다. 결과 문서를 남기고 이 범위 밖 전역 팔레트/버튼 재설계는 하지 않는다.
