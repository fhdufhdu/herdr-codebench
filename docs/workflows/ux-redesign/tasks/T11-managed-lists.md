# T11 공통 목록 관리 시안

2026-11-05. 사용자가 제공한 선택 목록·상단 툴바 패턴을 순서가 있는 관리 UI의 공통 기준으로 채택한다.

## 계약

- 툴바는 목록 위에 한 번만 둔다. 추가·삭제·복제·위·아래·편집은 해당 목록이 지원하는 동작만 표시한다.
- 단일 선택과 목록 스크롤을 유지한다. 첫째·마지막 항목의 이동, 선택 없는 삭제·복제·편집은 비활성이다.
- 검색은 이름·보조 설명을 찾는다. 검색 중 순서 조정은 비활성으로 표시한다.
- 방향키·Home·End는 선택을 이동한다. Alt+위·아래는 순서를 조정한다. 이동 후 같은 항목을 선택하고 보이게 한다.
- 프로젝트의 직접 지정은 별도 순서 관리창으로 이어진다. 취소는 기존 순서·정렬 기준을 보존하고 확인은 수동 순서를 적용한다.
- 설정의 도구 영역은 선택 목록과 우측 표시·위치 설정을 사용한다. 적용 전 draft를 유지한다.
- 연결 관리는 전역 연결 목록과 우측 연결 상세를 사용한다. 추가·삭제·복제·순서와 저장·취소가 HTML 상태에서 동작한다.
- 실행 구성도 같은 목록 렌더러와 동작을 사용한다. 기존 샘플 실행·중지·로그를 보존한다.
- 디자인 시스템 컬렉션에서 공통 목록 관리 예제를 제공한다.

## 구현 소유

부모는 HTML markup·CSS·각 목록 상태·저장과 취소·통합 검증을 소유한다. 하위 구현은 `/tmp/codebench-managed-list-component.js`의 `renderManagedList` 렌더러와 `results/T11-list-renderer.md`만 소유한다. HTML의 같은 파일 수정 충돌을 피하려고 하위 결과를 부모가 검토 후 삽입한다. 하위 effort는 스킬 기본값 medium이며 명시된 UI 계약 구현에 적합하다.

## 검증

실제 IAB에서 각 진입점과 선택·검색·키보드·경계 비활성·순서 보존·draft 취소·적용을 확인하고 스크린샷을 저장한다. 항목 이동 DnD는 사용자가 제외했으며 경계 크기 조절을 유지한다.
