# T29 하단 실행 출력·소유권 P0

09/T19 감사의 실행 위치·0ms/untracked 문제를 수정한다. run.js, execution-results.js와 필요한 신규 실행 전용 모듈/회귀 검사만 소유한다. database-editor.js·main.js·공통 UI/설정·사용자 설정은 부모 소유다. 후속 통합에 필요한 정확한 계약을 부모에게 전달한다.

idea에서 실행을 시작할 때 일반 터미널을 선택하거나 중앙 문서를 바꾸지 않는다. 하단 실행 결과가 소유한 실행별 화면·실시간 출력·상태·중지/재실행으로 연결한다. 코드 읽기와 실제 독립 synthetic command fixture로 소유권 공개 순서·새 실행·장기 실행·종료·복구를 검증한다. codebench legacy는 유지한다. native live terminal이 모드 내부에 없으면 지원되는 layout terminal block 경계를 사용하고 부모에게 통합 명세를 제시한다.

앱 재시작·사용자 실행 중지·실제 docker/DB 실행 금지. 설치/CUA는 부모만 한다. 결과 문서에 사실/추정/자동 검사의 한계를 구분한다.
