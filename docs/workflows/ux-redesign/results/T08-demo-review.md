# T08 HTML 데모와 리뷰 반영

2026-11-05. 예상 렌더링을 `design/ux-redesign-demo.html`의 self-contained HTML·CSS·JavaScript로 제공했다. 색은 canonical `herdr.ux`, 아이콘은 pin된 Lucide subset에서 가져왔다. 라이선스를 HTML 안에 보존하며 외부 라이브러리를 로드하지 않는다.

## 조작 범위

SQL 실행 범위 선택·샘플 진행 상태·취소, 테이블 셀 편집·Apply·Revert, 공통 CSV·JSON·SQL INSERT·TSV 추출 미리보기·복사·파일 출력, Markdown 원문·미리보기·편집 전환, 전역 연결 창과 프로젝트 정렬을 보여준다. 샘플 데이터와 로컬 DOM 상태로 동작한다. native 앱의 전체 기능 구현 상태를 데모로 판정하지 않는다.

## 사용자 의견 반영

- 프로젝트 영역의 열린 문서 목록을 제거했다. 중앙 탭으로 문서를 선택한다.
- 정렬 기준은 제목 줄 오른쪽의 108×26px 텍스트형 셀렉트다. 별도 정렬 행을 제거하고 테두리는 hover·focus 상태에서 드러낸다. 이름순·최근 사용순·직접 지정과 수동 순서 보존을 유지한다. 후속 의견에 따라 HTML의 수동 순서는 행의 `⋯`에서 맨 앞·다른 프로젝트 다음을 고르는 목적 위치 메뉴로 변경했다.
- 좌우 각각 위·아래 슬롯을 표시한다. 왼쪽 프로젝트·구조와 오른쪽 DB·터미널을 독립적으로 접고 열 수 있다. 상단 슬롯을 접으면 아래 슬롯이 공간을 사용한다. 이는 요청을 기존 4개 도킹 슬롯에 대응한 설계 판단이다.
- 테이블·기본 키·잠금·텍스트 선택의 아이콘을 canonical registry에 보완했다. native DB tree·tab·grid와 데모가 같은 계열을 사용한다.
- 좌우 너비·좌우 내부 위아래 높이·SQL 결과 높이·하단 도구 높이에 6개 경계를 제공한다. 포인터 드래그와 방향키·Home·End·Shift 미세/큰 단위 조절을 같은 크기 변경 로직에 연결했다. 최소·최대 크기를 제한하고 접은 영역의 내부 경계는 숨긴다. 실제 앱의 기존 native splitter와 panel 크기 저장 경계는 변경하지 않았다.
- 상단에 실행 구성 선택·실행·중지·구성 편집을 추가했다. 선택한 구성의 샘플 실행 상태와 로그는 하단 도구 영역에 표시한다. 기존 native 실행 기능을 데모에 표현했으며 HTML에서 실제 명령을 실행하지 않는다.
- 결과의 CSV 버튼과 다운로드가 같은 창을 여는 중복을 제거했다. 내보내기 하나에서 범위·형식을 선택하고 복사·파일 저장으로 출력한다.

native 프로젝트 선택창도 제목 오른쪽의 label 크기 셀렉트로 바꿨다. gpui-base Select·Popup과 기존 공통 button·MenuController·uiMenu를 조립했다. 고정 폭을 제거하고 기본 높이24·좌우 여백6·작은 chevron을 사용한다. trigger·list focus handle은 init에서 만들고 release에서 해제한다. 선택은 프로젝트 메뉴를 유지하고 Esc는 정렬 옵션만 닫는다. 기존 정렬 모델·저장 키·수동 이동 로직을 재사용했다.

## 검증

CUA의 실제 IAB에서 108×26px 정렬 셀렉트의 크기·세 기준을 확인했다. 최종 목적 위치 메뉴에서 현재 위치 비활성·맨 뒤로 직접 이동·맨 앞으로 복원·자동 정렬 후 수동 순서 보존·이동 결과 안내를 확인했다. 좌우 슬롯 접기·열기와 상단 접기 후 아래 슬롯의 855px 확장을 확인했다. 6개 조절 경계는 방향키로 너비·높이 변경을 확인했다. 포인터 드래그 경로의 실제 조작은 아직 확인하지 않았다.

상단 실행 구성 선택·편집 창·저장·샘플 실행·중지와 완료 로그를 확인했다. 내보내기 버튼이 하나임을 확인하고 같은 dialog에서 JSON 형식과 범위·복사·파일 출력 액션을 확인했다. 브라우저 오류 로그는 없었다. 앞선 데모 검증에서 SQL 범위·샘플 실행, 셀 더블클릭·확정·취소, Markdown 두 모드와 연결 창을 확인했다.

`check_project_order.mjs`는 native Select의 열림 callback과 공통 옵션 메뉴의 Home·Enter·Esc 경로, 선택 이후 프로젝트 메뉴 유지, 세 handle 해제를 확인한다. `check_surfaces.mjs`는 새 native 컴포넌트 mock으로 현재 Projects.render를 실행한다. 이 검사는 실제 앱의 OS 포커스 전달을 증명하지 않는다.

`herdr-app check`는 repo와 설치된 두 모드에서 통과했다. 실제 Herdr 클릭은 사용자 조작 감지로 중단되어 native 셀렉트의 포커스 확인이 남아 있다.

## 최신 후속 범위

사용자는 드래그앤드롭 이동을 제외하고 상하 이동 제어의 UX 대안을 요청했다. 항목 이동 DnD는 구현하지 않았으며 관련 임시 grip 자산과 스타일을 제거했다. 패널 경계의 크기 조절은 유지한다. native 프로젝트 선택창의 기존 이동 버튼과 HTML 목적 위치 메뉴는 현재 다르며 새 메뉴의 앱 이식은 별도 후속이다. [후속 시안과 검증](T10-settings-and-move.md)을 참조한다.
