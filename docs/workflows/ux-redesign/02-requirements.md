기존 `codebench` 레이아웃의 기능과 파일·터미널 데이터를 보존한다. 기존 macOS Ctrl/Meta 경계와 실제 엔진 기능을 유지한다. UX 원칙은 직접 조작·피드백·일관성·오류 예방·복구·키보드 접근성으로 검증 가능하게 적용한다.

2026-11-06 후속 목표로 단일 편집기·같은 UI/UX·LSP 연결이 검증되면 일반 소스 뷰어 역할을 제거한다. 이전 뷰어 유지 결정은 해당 기능이 충족되기 전의 현재 보호 경계다. 눈 아이콘 대신 상태를 읽을 수 있는 텍스트 전환과 Markdown preview를 유지한다. [상세 검토와 완료 기준](10-unified-editor-review.md).

좌우의 위·아래 요청은 기존 left·left2·right·right2 슬롯을 데모에서도 표현하는 것으로 해석했다. native 도킹 구성과 패널 크기는 유지한다. 정렬 셀렉트는 기존 세 기준과 수동 순서 보존을 그대로 사용한다.

최신 재계획은 [ADE 재구성 제안](12-ade-rebuild-plan.md)을 따른다. U14의 이전 목적 위치 메뉴 시안은 이후 사용자가 선택한 상단 툴바·목록·상세 관리 UX로 대체됐다. 위치는 좌우 위/아래와 하단의 다섯 개다. 작업 순서는 사용자 제안과 구현자 권고를 구분하며 현재는 계획 제안 단계다.
